Ember & Thyme is an original bistro cooking game: run a 3-minute shift, take tickets off the order board, chop, cook, bake, plate and serve against the clock — before patience runs out and guests walk away. Six recipes share ingredients in different prep combinations, so every ticket forces a new route through the kitchen; a dinner rush hits halfway through the shift. Keyboard (WASD/arrows, number keys) and mouse, plain static files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static HTTP server and open `game/index.html`.
